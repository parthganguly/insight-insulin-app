# Which dose response can be transferred?
Oxford is exposed development. The four Oxford 2026 outcomes, the earlier Oxford 2021 pea means and the Lund whey means were already known. This plan fixes the primary forecasts and objectives before running the new calculations; it does not make them blind. The new Dutch factorial is a separate evaluation, with its own exposure record.
Build a no-target-insulin source-specific curve by linearly interpolating the ratios of reported native 0–120 insulin iAUC means to each study's own glucose-only response. Use every published source knot including glucose at zero. Pea: Oxford 2021 administered 25/50 g NUTRALYS S85 Plus powder with 50 g glucose; Oxford 2026 used 10/20 g of that named powder plus 50 g glucose, supplying 8/16 g protein by its own table. Use *powder* grams on both sides. Whey: Lund used 4.5/9/18 g of actual protein with 25 g glucose; Oxford used 8.1/16.2 g in whey concentrate with 50 g glucose. Primary transfers the whey ratio by actual protein grams. Secondary transfers by protein/available-glucose ratio instead, evaluating 4.05/8.1 g in Lund. Do not enforce monotonicity or extrapolate past observed dose range. Document how much of each scale is truly measured; no product/lot-equivalence claim.
Construct separate source-specific least-squares lines RR=1+b*x from those same donor means as a low-flexibility comparator. Preserve other frozen food-only predictions: unadjusted named R, unfitted dose-mapped R and prior author-withheld named/dose/constant rules, energy and equality. All normalized forecasts use zero target outcome inputs. More knots use more data/flexibility, not a new assay. To challenge source specificity, use the same number of local linear knots but substitute the other source curve (nominal powder conversion from target composition explicitly a sensitivity); or test simple equal-weight average of the two curves at the same target low/high servings as a source-blind matched-donor comparator. No target fitting.
Separately evaluate absolute source-anchored native forecasts for all four Oxford 2026 arms: multiply each predicted ratio by Oxford 2021 glucose mean 3369.6. This number is an earlier public cohort mean; it is not the 2026 control, the consumer's own insulin, or an input from evaluation. Same-laboratory, product, glucose load and assay strengthen the anchor for pea. The whey forecast adds the cross-lab response-ratio assumption. Record µU·min/mL compatibility/printed units and source baseline/area qualifications; target primary here is author-reported 120-minute iAUC. No clinical individual or population calibration inference. Native MAE and ratio-of-means log loss separately. Show actual 2026 control as an endpoint check only. Compare absolute against the previous constant, dose, named/energy baselines on exactly the same external anchor; include a cheap historical mean response level from earlier pea data if used and disclose coverage.
Primary discriminating quantity: source-by-dose ratio-of-ratios, (whey-high/pea-high)/(whey-low/pea-low); score absolute log error, compare tie (no source-dose change), earlier common gain, external linear slopes and unfitted dose-adjusted references. Also report errors for both within-dose source contrasts, both source dose steps, all four relative and native levels. Success requires improving the interaction point forecast AND average 4-level log loss over the prior calibrated named candidate; disclose stronger alternatives regardless. No paired CI for the interaction from marginal SD alone. This specification provides actual wearable-free/native forecasts in one well-annotated lab protocol, not consumer validation.
